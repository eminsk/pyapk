Pure Python Движок для
Android APK & Мульти-Стор Упаковщик

Забудьте про гигабайты Android SDK, NDK, Java и Gradle. Скоростной парсинг через zero-copy memoryview, нативное 16-килобайтное выравнивание под Android 15, распаковка Android Wheels и экспорт в Google Play, Apple App Store и Windows Store.

pip install pureapk

Почему pureapk уникален?

Создан с бескомпромиссным вниманием к автономности, скорости и отсутствию внешнего мусора.

🚫

Без Java и Android Studio

Никаких 15–20 ГБ SDK, NDK, OpenJDK и Gradle. Все операции с APK (бинарный AXML, DEX, 16KB-выравнивание, подпись) работают на 100% чистом Python за секунды.

📱

Android 15 Ready (16KB)

Нативная реализация стандарта Google 16KB Page Alignment для бинарников .so с официальным тегом 0xd935. Больше не нужен системный zipalign.exe.

🔧

Моддинг и Доработка APK

Извлечение любого существующего APK, замена кода или манифеста, добавление wheels, авто-очистка старого META-INF/ и переподпись v1/v2 в одну команду.

🏬

Мульти-Стор Вселенная

Прямая генерация пакетов для Google Play (.aab), Apple App Store (.ipa с Info.plist), Microsoft Store (.msix с 64KB AppxBlockMap) и китайских сторов (--channel).

🧩

Android Wheels & Cython CI

Инспекция и распаковка предсобранных .whl пакетов с раскладкой .so в lib/<abi>/. Авто-генератор GitHub Actions CI для сборки Cython NDK в облаке.

⚡

Zero-Copy & No-GIL

Использование __slots__ во всех классах, парсинг срезами memoryview и 100% подтверждённая потокобезопасность на Python 3.13t–3.16t (Free-Threaded No-GIL) и PyPy.

🩺

Телеметрия и Краш-Репортинг

Встроенный модуль pureapk.telemetry: авто-запись стек-трейса в /sdcard/Download/app_crash.log и визуальный экран восстановления Kivy при любых сбоях.

🚀

Нативный Рантайм Python 3.10

Команда prepare-runtime внедряет скомпилированные библиотеки libpython3.10.so, libkivy.so, libSDL2.so и Multi-DEX для превращения скелета в живой APK.

🛡️

Защита Оборудования Android 10+

Авто-патч AliasProperty для плотности экрана (DPI) и метаклассов PyJNIus Cython 3. Исключает падения Hardware.getDPI() на современных версиях Android.

Поддержка Всех Популярных GUI Фреймворков

Шаблонизация, синтез манифестов и мгновенная упаковка в APK в один клик.

Terminal & Python API 
# 1. Инициализация каркаса проекта
pureapk init-kivy my_kivy_app --title "My Kivy App"

# 2. Установка чистых Python зависимостей прямо в проект
pureapk install-deps my_kivy_app/ requests urllib3

# 3. Мгновенная упаковка в релизный APK с 16KB выравниванием и цифровой подписью
pureapk pack-kivy my_kivy_app/ -o app.apk --release

# Либо мульти-канальная сборка под китайские маркетплейсы
pureapk pack-kivy my_kivy_app/ -o app_huawei.apk --channel huawei --release
Pygame-CE Terminal 
# 1. Создание каркаса аркады на Pygame
pureapk init-pygame space_shooter --title "Space Shooter 2D"

# 2. Упаковка в Android APK (настройка ориентации landscape, OpenGL ES 2.0)
pureapk pack-pygame space_shooter/ -o shooter.apk --release
Python Telemetry & Crash Guard 
from pureapk.telemetry import setup_crash_reporter, get_device_info

# Инициализация телеметрии в начале main.py
reporter = setup_crash_reporter(app_name="MyMobileApp")

# Метаданные платформы и оборудования (Android model, ABI, CPU)
info = get_device_info()
print("Device info:", info)

# Автоматический перехват: при любом исключении стек пишется в
# /sdcard/Download/app_crash.log и выводится экран аварийного копирования.
reporter.emit("INFO", "Приложение запущено")
Prepare-Runtime CLI & Python 
# 1. Развернуть нативный рантайм (libpython3.10.so, classes.dex, resources.arsc)
pureapk prepare-runtime --from-apk base_template.apk ./my_project

# 2. Собрать и подписать полноценный нативный APK
pureapk pack-kivy ./my_project -o my_app.apk --release

# 3. Проверить нативную готовность к запуску на устройстве
pureapk verify my_app.apk
Flet / Flutter Terminal 
# Создание и упаковка современного Material 3 приложения
pureapk init-flet my_flet_app --title "Flet Dashboard"
pureapk pack-flet my_flet_app/ -o flet_app.apk --release
BeeWare Toga Terminal 
# Нативные системные виджеты ОС без лишних абстракций
pureapk init-toga native_app --title "BeeWare Native"
pureapk pack-toga native_app/ -o toga.apk --release
HTML5 + Python Backend 
# Запуск веб-приложений через встроенный WebView Android
pureapk init-webview web_app --title "HTML5 Hybrid"
pureapk pack-webview web_app/ -o webview.apk --release
PySide6 / PyQt Terminal 
# Qt for Android интеграция
pureapk init-pyside qt_project --title "PySide6 App"
pureapk pack-pyside qt_project/ -o qt_app.apk --release
Multi-Store Distribution API 
# Google Play: Сборка Android App Bundle (.aab)
pureapk pack-aab my_project/ -o release.aab

# Apple App Store: Генерация Info.plist и упаковка .ipa
pureapk init-ios ios_app --title "MyIOSApp" --bundle-id "com.company.app"
pureapk pack-ipa ios_app/ -o release.ipa --title "MyIOSApp"

# Microsoft Store: Генерация AppxManifest и .msix с 64KB BlockMap хешами
pureapk init-windows win_app --title "MyWinApp" --package "MyCompany.App"
pureapk pack-msix win_app/ -o release.msix

Доработка, Моддинг и Переподпись Готовых APK

Полный рабочий цикл обновления существующих APK без единой строчки Java или Android SDK.

1

Распаковка APK

Извлеките файлы, ассеты, манифест и код из любого существующего APK-файла.

pureapk extract app_v1.apk ./workspace/
2

Внесение Доработок

Обновите код, подкиньте нативные Android Wheels (.whl) или чистые библиотеки из PyPI.

pureapk unpack-wheel numpy.whl ./workspace/
3

Выравнивание & Подпись

Сборка v2: очищает старый META-INF/, выравнивает под Android 15 (16KB) и подписывает v1/v2.

pureapk pack ./workspace/ -o app_v2.apk --sign

Центр Установки

Доступно во всех ведущих репозиториях пакетов.

PyPI (Официальный релиз)

Установка стандартного легковесного пакета (~50 КБ, 0 зависимостей):

pip install pureapk

Conda / Mamba / Pixi

Установка из канала Anaconda.org:

conda install -c m_n_nik pureapk

Ubuntu / Debian APT PPA

Официальный системный репозиторий APT:

curl -sS https://eminsk.github.io/ppa/setup.sh | sudo bash
